# BMF's Town —— BMF的城镇

让 NPC 镇民住进你的世界：他们吃掉你过剩的食物、替你站岗打怪、替你翻遍全城的箱子找东西——还有一整套会开心会闹脾气的喜好、性格与特性。

- **mod id**：`bmfstown`　**包名**：`com.bmf.bmfstown`
- **MC**：1.21.1　**NeoForge**：21.1.x
- **当前版本**：v0.13.0

## ✅ 已实现

- **城镇**：魔杖两点框领地 → 手册建镇/改名/删除/预览图，线框常驻
- **功能区**：食堂（扫箱觅食）、住所（共享床位、天黑回睡、越界回家）
- **镇民**：随机中文姓名、饥饿进食（挑食：爱吃组优先）、自然回血、睡觉作息（没睡好逐夜扣心情）、开门关门
- **心情系统**：三管线（即时事件/每日结算/感知扫描）+ 想法日志三色可见；<40 减速、<20 罢工
- **喜好（真生效）**：食物口味 / 工作喜好 / 建材×2（住宅区整区扫描）/ 动物 / 颜色 / 音乐 / 讨厌天气 / 讨厌敌对生物
- **性格 9 选 1**：攀比 / 好战 / 胆小 / 爱热闹 / 贪吃 / 乐观 / 悲观 / 和平主义者 / 爆炸主义者
- **特性 14 选 1**：轻浮 / 鼓手主唱 / 海象 / 大智若愚 / 末影步 / GATTACA（伪装复制整套数据，跳天复原）已实装，出现概率可配权重（`traits.weightOverrides`）；其余 8 条计划中
- **熟练度**：10 段位（生疏→传奇），效率 60%→150%
- **战士**：跟随/站岗、索敌打怪、六天赋（再生/强壮/坚盾/追猎/嘲讽/斩杀，原创音效+视觉反馈）
- **工人**：工坊自动合成红石元件——绑定合成台/原料箱/产物箱，配方实时反查游戏真实配方；天赋树（效率/节能、布线/机关、开源/节流）+ 开箱动画/小锤子气泡
- **炼金术士（v0.12.0，第四职业）**：酿造台岗位自动认领、订单制真酿造（配方全反查原版真实酿造表：普通/延时/强化/喷溅/滞留全组合）；**纯度系统**（段位爬升 0.6→0.9、clamp≤1 永不超越玩家、只影响时长；浊药"浑浊的××"必窜杂质：7 持续+1 瞬发对称池、喝下/命中现抽）；**秘传配方 11 条**（原版不可酿：急迫/抗性/伤害吸收/生命提升/幸运/凋零/失明/黑暗/反胃/挖掘疲劳/悬浮）——隐藏秘方书解锁、门禁双面（未解锁玩家手酿无反应）；**龙息 NPC 专属合成**（紫颂果+烈焰粉+玻璃瓶，玩家无此配方）；**Perk 六件套**（冷萃/猛火、医师/毒师、缓释/浓缩）；一套原料 4 瓶；等料可视化播报（点名缺什么）；**v0.12.1 增强**：目录全收录（两步腐化链伤害/缓慢/隐形 + 水瓶直酿虚弱，柔性链按库存选路）、**水源站**（第四登记池，空瓶自动取水，炼药锅 1 格=1 瓶做实）、悬浮秘传改缓降+腐蛛眼、经验按链长批结算
- **烟火工匠（v0.13.0，第五职业）**：工作台岗位自动认领（与工人共池先到先得），面板**星配置器两段弹层**下烟火订单——火药 1~3 + 星列表（8 格共享约束 m≤8−n 服务端复核）；星星全走**原版特殊配方真实 assemble**（`FireworkStarRecipe`/`FireworkStarFadeRecipe`，造星→渐变两段跑）：形状 5 种、**主色多染料 ≤8−形状物−钻石−荧石**、**渐变 ≤8**、轨迹（钻石）/闪烁（荧石）；**节流 I/II/III 材料节省阶梯**（10% 免染料 / 20% 免钻石荧石 / 形状物恒免——火药永远要花）；**战斗三件**：破片（半径 5→6）/ 装药足量（伤害 ×1.25）/ 回响（0.5 秒后二段爆 50%），天赋物化成带章火箭（悬浮提示三行彩色可见），无章火箭原版行为零变化；XP 30/件
- **自动化测试（v0.13.0）**：NeoForge GameTest 框架 61 用例（炼金 46 + 烟火 15：订单键解析/真实 assemble/端到端/共池/伤害与二段爆炸），`gradlew runGameTestServer` 无头一键回归；lang 双语审计脚本
- **簿记员**：全城容器物资统计、创造式搜索界面（精度随段位成长）、寻物带路+绿粒子标记、夜间叫醒带路
- **不连续子区域**：城镇可追加任意多块不连续区块（手册"＋增加选区"，手持手册选两点创建）；功能区归属所在区块、按区块管理与改名删除；镇民"在城中"= 各区块并集判定，跨区块出行放行（修桥搭路自然改变可达性）；持魔杖可视化全部区块
- **城镇手册**：城镇 → 区块 → 功能区三级导航；居民列表（排序/滚动条/点击开面板/免距离/传送/关闭回跳）
- **镇民台词（表达层 P1）**：吃到爱吃的食物、天气转晴时镇民头顶冒一句白字（10 秒、跟着人走）；嘴忙锁防插嘴、按人按类冷却；事件总线驱动（v0.9.1）
- **镇民历与挂历（v0.9.3）**：自带纪年——月 = 8 天与原版月相同步（**1 号恒为满月**）、年 = 12 月 = 96 天、纪元为 mod 启用当天；挂历方块贴墙/平铺/吸顶，右键在物品栏上方报日期
- **昼夜流速（v0.10.1）**：`/bmfstown timespeed 0~1000` 真连续倍速（原生浮点推进，太阳平滑、睡觉跳夜照常、0 倍冻结也能跳夜）
- **记忆域（第七域，v0.9.1 起）**：印象池按事件采集、带日期、每日衰减归零遗忘；**铭记系统（v0.10）**——挨饿/缺觉受苦累计进度，积满固化为永久记忆（紫色想法宣布、永不衰减、同类事件心情额外 -10、台词换旧事变体），收手每日 -5 淡忘
- **解锁与发现（v0.10.1，v0.10.2 两级线索）**：内容在探索中徐徐展开——工人/簿记员初始锁定（数据层过滤）；**引导线**（携带红石块/矿，镇民偶尔提示"这东西可以加工哦"，城镇×玩家 5 分钟冷却）+ **解锁线**（背包同时携带 ≥3 种红石元件，镇民复述并当场解锁工人）；解锁瞬间全服双色公告+提示音；访问空间=城镇，各镇独立进度（详见 GitHub Wiki《解锁与发现》）
- **学识制知识系统（v0.11.0）**：图书馆是**唯一**的读书场所——读闲书 +1 学识 + 心情，学技能书消耗 5 学识（`leisure.literacyCost`）：从书架取技能书站着读（逐 tick 累计、跨段续读、批注本 1.5 倍速），读满登记时长学成进已学列表；**效果单选槽**——已学多本共存、同时只生效一本，知识页点选/再点取消；闲书不读重复（种子记忆）；**书本双广播**：写出特殊书时全服"已发现 隐藏书籍《X》"（同镇永久闩锁），任何人学会时"X 学会了《Y》"；知识页显示可用学识与累计阅读
- **跟随见习（v0.11.0）**：perk 书 50% 卡点时工作页出现"跟随见习"按钮 → 对口学科从业者清单 → 点人开面板确认 → 学者手动指定跟随目标（观战计数解除卡点），服务端三重校验
- **效率公式行全因素化（v0.11.0）**：工作效率逐段连乘（段位×心情×各职业天赋×特殊书效果），每段悬停可解释——学者六因素（辩证法/分工/过拟合/写书速度/活字印刷）与工人合成速度全部可见；战士的近战伤害加成作用于攻击力，以独立"⚔+N%"信息段展示
- **抄本体系（v0.11.0）**：抄本悬浮显示"抄本 · 抄工：X"，作者链保留底本作者全列 + 追加抄工；抄工的批注 perk 作用于抄本（抄本即批注本，耗时 ×1.5 随之）
- **学者休闲与读书（v0.10.4）**：动态闲暇活动池（闲逛/图书馆看闲书，酒吧等以后加一行即入池）——无业全天、有职业者晨间+下班+周末（星期系统：纪元 1/1=周日，挂历显示星期几）；看书全物理流程：真从书架取闲书、主手拿书（原主手换背包绝不弄丢）、站着读 600t 结算心情+想法（批注本 +8）、还最近书架空位；看书气泡按书名词位动态补全（"村民吃面包，绝了"）；技能书学习现走学识制（见上）
- **学者系统（v0.10.3）**：图书馆（工作区选区改名复用）里的写书人——扫描区内容器取 1 书+1 墨，讲台开写（gameTime 在岗 tick 累计，/time 系影响不了），成书插入雕纹书架；**不放回奖池**：抽中特殊书即从该镇池子移除（30% 概率，销毁退池），未命中写闲书；闲书由"名词（物品+方块+实体全表）×修饰语（buff 全表）×MC 动词"六句式拼装书名与内容（确定性种子，双语自动）；perk 书 50% 卡点——写书人是传奇或**跟随该职业从业者实践**（观战杀敌/观察合成计数）解除；作者链记名字，死者也是作者；**知识页**：装备已学书研读习得；工作页书稿真槽位（拿起/放回/Shift 搬运）+ 研究进度百分比
- **魔法降雪**：`/bmfstown snowfall` 任意群系限时局部下雪（含消融）
- **觅食挑箱**：全镇范围内"含爱吃的最近箱"优先，没有爱吃的才退回"营养最低食物的最近箱"；普通食物按营养最低拿取（防浪费）
- **调试命令**：`/bmfstown hunger|mood|skillxp|reroll|trait|say|date|snowfall|timespeed|unlock|lock|unlocks|bookprogress|booklearn`
- **全量配置**：`bmfstown-common.toml`，10 个命名空间 60+ 参数，中英注释

## 📁 目录约定

```
docs/                           ← 需求分析说明书、开发备忘 wiki（卷五~卷八）
src/main/java/com/bmf/bmfstown/
├── BmfTown.java                ← 主入口：只负责挂注册器
├── ModItems / ModBlocks / ModEntities / ModSounds / …
├── block/                      ← 方块（挂历等）
├── calendar/                   ← 镇民历（纪年与月相换算）+ 昼夜流速
├── client/                     ← 渲染、屏幕（面板/手册/搜索屏）、客户端状态镜像
├── command/                    ← /bmfstown 调试命令
├── config/Config.java          ← 全部玩法数值
├── entity/
│   ├── Resident.java           ← 镇民本体（组装根 + 生理/AI 状态机）
│   ├── domain/                 ← 七域持久数据（v0.9 重构 + v0.9.1 记忆域）
│   │   ├── Identity / Growth / Prefs / Status / TraitState / JobState
│   │   ├── MemoryState         ← 记忆域（印象池+铭记库，第七域）
│   │   └── ResidentSnapshot    ← 多域同步快照（面板数据源）
│   ├── HomeMaterialScanManager ← 住宅区建材/颜色摊派扫描
│   └── profile/                ← 偏好枚举表、饥饿系统、段位、perk 表、职业表
├── menu/                       ← 面板菜单
├── network/                    ← 网络包（同步载荷）
├── social/                     ← 事件总线 + 台词引擎（表达层）
├── unlock/                     ← 解锁与发现（登记表/状态仓/职业锁定/职业线索）
├── weather/                    ← 魔法降雪
└── town/                       ← 领地、功能区、手册、魔杖
```

> **七域架构**：镇民持久数据按"身份/成长/偏好/状态/特性/岗位/记忆"七个域对象存储，
> 各域独立 save/load（老存档自动迁移）。加新喜好 = 加一个 `PrefKind` 枚举值；
> 加新特性 = 在 `TraitState.data` 用自己的键；加新职业 = 在 `JobState.data` 用自己的键；
> 加新记忆事件 = 在 `MemoryState.recordEvent` 登记重要性。
> 详见需求分析说明书 §0.0。

## ➕ 加新内容的固定套路

以物品为例，四处同步缺一不可（否则紫黑方块或原始 key）：

1. `ModItems.java` 注册
2. `assets/bmfstown/models/item/xxx.json` 模型
3. `assets/bmfstown/textures/item/xxx.png` 贴图
4. `lang/en_us.json` + `lang/zh_cn.json` 名称

机制类改动的 know-how（踩坑记录、禁手）见**开发备忘 Wiki 卷七**。
