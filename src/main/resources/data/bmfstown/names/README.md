# 镇民名字池（data/bmfstown/names/*.json）

登记制，可放多个文件（每个文件一个"包"，同文本条目自动去重、首见优先）。
**v0.16 起为前缀+后缀制**（名单 2026-11-20 定稿，组合规则 2026-11-21 拍板，
2026-11-24 按《城镇mod命名系统.xlsx》更新词表）：
名字 = 随机前缀 + 随机后缀**直接相连**（无分隔符，如 黑山羊 / 活闪电 / 黑山脉之子）。

## 格式

```json
{
  "prefixes": [
    { "group": "animal", "onlySuffixGroups": ["animal"], "items": ["黑", "狼"] },
    { "group": "special", "excludeSuffixContains": ["之"], "items": ["呼吸的"] }
  ],
  "suffixes": [
    { "group": "item", "items": ["之剑", "铁锄头"] },
    { "group": "terrain", "weightPerItem": 0.5, "items": ["山脉"] }
  ],
  "names": ["阿竹"]
}
```

- `prefixes`：前缀分组池。每项可选：
  - `excludeSuffixContains`：禁配——后缀文本**任何位置含**这些串都不组合
    （特殊/动词组"之与'的'不能共存"；这类前缀也**不追加'之子'**）
    （2026-11-21 用户收紧：不再只是"开头是之"）；
  - `onlySuffixGroups`：组限制——本组前缀**只**与列出的后缀组组合
    （动物前缀只能配动物后缀，组内颜色词同理）；
- `suffixes`：后缀分组池。每项可选 `weightPerItem`（默认 1.0）——该组每条
  后缀的抽取权重（地形组 0.5 = 概率是别组的一半）；
- `names`：可选整名池（前缀/后缀池全空时才回落）；
- 旧格式键 `surnames`/`given` 仍兼容（按无约束前缀/后缀并入池）。

## 取名规则（按优先级）

1. 前缀池与后缀池**都非空** → 随机前缀 + 按约束筛后缀 → 按权重抽后缀 → 直连；
2. 后缀带 `group=terrain` 时 30% 概率追加"之子"（黑山→黑山之子；禁配'之'
   的前缀不追加；后缀自身含'的'的也不追加（推定）；动物前缀只配动物组走不到这里）；
3. 组限制/禁配把候选筛空 → 放开全后缀池兜底（绝不无名）；
4. 否则回落 `names` 整名池直接抽；两边都空 → 镇民无名（合法状态，不炸）。

## 字段说明

- `group` **参与机制**：`onlySuffixGroups` 按它匹配、`group=terrain` 触发
  "之子"规则与半权重；组 id 自定义（新组随意起名，配对用）；
- 空串/非字符串条目 warn 跳过；跨组跨文件重复文本自动去重（首见优先，
  约束差异以先出现者为准）；
- 镇内去重：生成时排除已被本世界镇民占用的名字（重试 10 次），全占用则接受重复。

## 修改生效

数据包重载即生效：游戏内 `/reload`，或重启世界。存量镇民**不会**改名
（名字终身保留 + 玩家命名牌优先），只有新镇民/无名镇民会用新池。

## 内容纪律

`core.json` 即用户定稿名单（来源：城镇mod命名系统.xlsx）。改名单直接改这个
文件，机制对数量无上限假设。颜色前缀组已于 2026-11-21 移除（与动物组重复，
动物组自带颜色词）。
