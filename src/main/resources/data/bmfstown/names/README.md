# 镇民名字池（data/bmfstown/names/*.json）

登记制，可放多个文件（每个文件一个"包"，同名条目自动去重）。格式：

```json
{
  "surnames": ["陈", "周"],
  "given": ["满仓", "铁栓"],
  "names": ["阿竹", "老陈"]
}
```

## 取名规则

1. `surnames` 与 `given` **都非空** → 随机组合"姓+名"（如 陈满仓）；
2. 否则回落到 `names` 整名池直接抽；
3. 两边都空 → 镇民无名（合法状态，不炸）。

## 字段说明

- 三个字段全部可选；多余键（如 `_comment`、`pack`）被忽略；
- 空串/非字符串条目 warn 跳过；跨文件重复条目自动去重；
- 镇内去重：生成时排除已被本世界镇民占用的名字（重试 10 次），全占用则接受重复。

## 修改生效

数据包重载即生效：游戏内 `/reload`，或重启世界。存量镇民**不会**改名
（名字终身保留 + 玩家命名牌优先），只有新镇民/无名镇民会用新池。

## 内容纪律提醒

`core.json` 当前是**初稿占位**（2026-11-09，机制落地用），正式名单由用户定稿后
直接改这个文件即可，机制对数量无上限假设。
