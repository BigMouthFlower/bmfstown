# 卷一 · 基本操作与机制

## 1.1 物品 ✅

| 物品 | 用途 |
|---|---|
| 城镇魔杖 | 左/右键两个方块，两点为对角框出长方体区域 |
| 城镇手册 | 建镇、命名、管理功能区；边界线框常驻显示 |
| 城镇凭证 | 占位物品（早期骨架遗留） |

## 1.2 领地与城镇 ✅

1. 手持魔杖框出长方体区域，自动登记为功能区；
2. 打开城镇手册建镇/命名/删除；
3. 建镇时截取主视角生成**领地预览图**（存于存档 `bmfstown/towns/<名字>.png`）。

## 1.3 功能区类型 ✅

| 类型 | 用途 |
|---|---|
| 食堂（就餐区） | 镇民饿了来这里扫箱子拿吃的；箱子公用 |
| 住所（住宅区） | 区内床位共享，镇民天黑回去睡；**建材/颜色喜好的判定范围就是整个住宅区** |
| 其他 | 预留，后续职业的工作区 |

## 1.4 镇民面板 ✅

右键镇民打开，**五个页签**（按页收缩高度）：

| 页签 | 内容 |
|---|---|
| 资料 | 姓名、饥饿、心情分档文字、职业与段位（彩色稀有度风格）、效率行、城镇摘要 |
| 归属 | 本维度城镇列表，点击绑定/解绑 |
| 工作 | 职业列表（滚轮翻）、跟随/站岗按钮、经验条、perk 天赋选档 |
| 喜好 | 10 行偏好一览（口味/工作/建材×2/动物/颜色/音乐/天气/生物/性格） |
| 想法 | 心情想法日志（30 条环形，三色，详见卷四 4.12） |

> **同步时机**：想法/偏好/心情只在**打开面板瞬间**同步——做完动作要重开面板才能看到变化。

## 1.5 时间与结算机制 ✅

- 一切"一天"的判定**以 `dayTime/24000` 为准**，不用 gameTime（兼容慢速昼夜数据包与 `/time add`）；
- 每个 NPC 有随机结算相位 `settleOffset`（出生定、落档），每天结算时刻各不相同——**负载天然摊开**；
- 跳天（`/time add 24000`）必触发一次结算。

## 1.6 配置 ✅

全部玩法数值集中在 `config/bmfstown-common.toml`，按命名空间分组：
`residentAttributes.*`（基础属性）、`hunger.*`（饥饿）、`growth.*`（成长）、`mood.*`（心情 27 项）、`ai.*`(觅食)、`sleep.*`（作息）、`warrior.*`（战斗）、`perk.*`（天赋）、`craft.*`（工人工坊）。
**完整参数表见[卷五](#卷五--参数手册)**。UI 坐标、存档格式类数值刻意不配置化。

# 卷二 · 镇民

## 2.1 出生 ✅

- 随机中文姓名；
- 随机整套偏好（见卷四）+ 性格 9 选 1（必出 1 条，终生不变）；
- 饥饿满、心情初值 50（`growth.initialMood` 可配）——出生只是"还行"，让玩家有经营空间。

## 2.2 生理：饥饿与进食 ✅

**饥饿**随时间下降（默认每分钟 1 点）；饥饿 < 18 不回血。

**进食决策**（每口都按顺序判断）：

1. **回血优先模式**（血未满且饥饿 < 18）：无视偏好与浪费，能吃就吃——保命第一；
2. **背包里有爱吃的、且吃了不浪费** → 吃它（组内挑营养最低）；
3. **背包里还有爱吃的东西**（只是现在吃会浪费）→ **挑食等待**：拒绝普通食物，等饥饿降下来；
4. **背包里没有爱吃的** → 普通食物里挑"吃了不浪费、营养最低"的；
5. 背包彻底没食物 → 触发**觅食**。

"不浪费" = `饥饿 + 营养 ≤ 20`。挑食等待不会饿死也不会误报挨饿（挨饿事件只挂在觅食失败上）。

## 2.3 生理：觅食 ✅

- 触发：饿了 + 背包无任何食物 + 已绑定有就餐区的城镇 → 走向最近食堂；
- **偏好拿取**：扫箱两遍——第一遍只拿爱吃的，不够再补普通，总数 3 个（`ai.forageTakeCount`）；
- 就地开吃（对调主手动画）；
- 寻路失败逐级降级：重推导航（≥10 tick 间隔）→ 直接扫全城箱 → 贴近 6 格直取；失败日志升 WARN 带坐标。

## 2.4 生理：睡眠 ✅

- 日落（`sleep.startTime`）回住宅区，从近到远挑第一张空床；躺下即登记住址；
- 天亮（`sleep.endTime`）起床；床被拆/被占自动重挑；被玩家叫醒则同步状态；
- 越出领地自动回家（赶路速度）；战士工作中不睡觉（就餐照常）；
- **没睡好会扣心情（v0.8.1）**：每日结算时检查"昨晚躺过床没"——没躺 → **−3/夜**，连续没睡**逐夜叠加不封顶**（漏两夜 −6，漏三夜 −9……）；**战士守夜豁免**（跟随时/站岗中不睡是职责，不罚也不追溯）；没有床的镇民因此会持续掉心情——**多修床**。

## 2.5 熟练度与效率 ✅

- 每职业独立经验，共用 10 段位累计阈值（**存档语义，发布后只增不改**）：

| 段位 | 生疏 | 入门 | 熟练 | 精通 | 老练 | 专家 | 大师 | 宗师 | 神话 | 传奇 |
|---|---|---|---|---|---|---|---|---|---|---|
| 累计经验 | 0 | 100 | 250 | 500 | 900 | 1500 | 2400 | 3600 | 5200 | 7500 |
| perk 节点 | | | | **①** | | | **②** | | | **③** |

- **效率 = `0.6 + 0.1 × (段位 − 1)`**：Lv1=60%，Lv5（专家）=100% 回本点，Lv10（传奇）=150%；纯代码常量；
- 经验只来自工作成功的过程（战士击杀 +30）；无在岗挂机成长；
- 段位 UI 泰拉瑞亚稀有度风格九色，最高段位彩虹渐变；满级经验条整条填满绿色。

## 2.6 心情分档 ✅

范围 0~100，面板资料页只显示**分档文字**不给数字。

| 心情 | 效果 |
|---|---|
| < 40 | 工作效率 ×0.7（`mood.slowMultiplierPercent`） |
| < 20 | **罢工**：跟随/站岗/主动索敌全停；**正在打的架要打完**，被打还手照常 |

## 2.7 城镇手册 · 居民列表与镇民管理 ✅（v0.8.1）

- **居民列表**：城镇手册城镇页左下——两列表头（名字/职业），点击表头排序
  （首点该列 = 降序 ▼，再点 = 升序 ▲，循环），默认按名字升序；滚轮翻行；
- **点击居民行** → 打开该镇民的面板。此方式**不走交互锁**：NPC 不会被拉过来
  面对玩家、干活不被打断；面板**免距离限制**（远距离也能看，镇民死亡才关）；
- **关闭回跳**：从手册打开的镇民面板，关闭（ESC/✕）后回到城镇手册刚才的城镇页；
- **传送按钮**：镇民面板资料页，"重命名"旁新增"传送"——把玩家传到该镇民身边
  （支持跨维度），正常生存可用、无权限要求；
- 城镇手册退出：ESC 或 **E** 键（改名输入模式中 E 是打字）；
- 簿记员搜索屏退出机制同步调整：点空白不再关闭，**ESC / E** 退出
  （搜索框聚焦时 E 是打字，回车提交后焦点移出，E 生效）。

## 2.8 簿记员夜间叫醒带路 ✅（v0.8.1）

夜晚（含回家路上/找床中/已睡着）在搜索屏点物品 → 簿记员**被叫醒立即带路**
（不躺回去等天亮）；带路差事期间睡眠/觅食流程都让位（不半路回床、不跑去吃饭）；
带完自动恢复正常夜间作息（自己回床接着睡）。

# 卷三 · 职业

## 3.0 通用规则 ✅

- 职业在面板"工作"页指派；效率、经验、perk 按职业独立；
- 心情的职业好恶按**当前职业**判定（数据驱动，新职业自动参与，v0.8.1 重构）；
- **全体镇民会开门**（照抄村民）：寻路把关闭木门当可通行节点，撞门即开、走过去关门；铁门/栅栏门不管（村民同款）；
- 资料页名字右侧有**重命名**按钮：输入屏回车确认（1~32 字符）、ESC 取消，落原版 CustomName NBT。

## 3.1 无业 ✅

默认状态；不参与职业好恶结算；不索敌。

## 3.2 战士 ✅

### 工作模式
- **跟随**：跟在绑定玩家身边（`warrior.followSpeed` ≈ 玩家疾跑），14 格外传送归队；
- **站岗**：守在指定锚点周围巡逻（红色半透明预览选取，右键确认 / Shift 取消）。

### 索敌
- 每 10 tick 扫锚点半径内敌对生物（`Enemy` 接口口径，含史莱姆/岩浆怪）；
- 苦力怕默认不打（`warrior.attackCreepers=false`，近战会引爆它）；
- 追击半径放宽到 2 倍，防"刚接战就脱战"抖动；
- 出手距离 `warrior.attackReach`（2.5 格，村民原版只有 1.2）。

### Perk 天赋（3/6/9 级各选一，免费改选，服务端复核）✅

| 节点 | 防御 | 进攻 |
|---|---|---|
| 3 级（精通） | **再生**：自然回血 ×1.5 | **强壮**：效率 +10% |
| 6 级（大师） | **坚盾**：5 格友军含玩家抗性 I，15s | **追猎**：20 格敌怪发光，20s |
| 9 级（传奇） | — | **嘲讽**：10 格强制索敌 10s / **斩杀**：25% 概率秒杀 ≤50 血 |

- 主动技（坚盾/追猎/嘲讽）战斗中自动施放，30s 共用冷却；
- 声光反馈：四种原创音效 + 嘲讽红罩（半透明渲染层）+ 斩杀红色粒子；
- "节点:分支"格式存档，兼容老档。

### 罢工的边界 ✅
罢工停的是"工作"（跟随/站岗/主动索敌）；**已经在打的架要打完**。

## 3.4 工人 ✅（v0.8.1 实装）

**定位**：工坊里的自动合成工——生产红石元件，慢速人力小作坊（与机械动力的工业化错位）。

### 工作流程

1. **绑定**：面板点「设置工坊」→ 依次右键 **合成台（蓝）→ 原料箱（橙）→ 产物箱（绿）**（Shift 取消）；绑定永久保存，重绑才覆盖；
2. **订单**：点产物格 → 合成书式弹层列出**当前能做的配方** → 点击下单（订单存产物注册名）；
3. **开工**：点「开工中/已停工」开关控制；工作时段内自动循环：**取料（≤3 套一批）→ 合成台倒计时 → 成品入产物箱**；
4. **表演**：开箱有开关盖动画+音效（与觅食共用原语）；干活时头顶有**小锤子气泡**；面板状态行实时显示"工坊/订单/阶段"。

### 配方：白名单 + 游戏配方反查（不手写）

- 白名单只圈**产物域**（15 个红石元件，按信号语义分三线：信号源人人可做；布线/机关线看 Lv6 大师分支）；
- **材料与产量从 RecipeManager 真实配方实时反查**——原版配方是啥就用啥（产量如绊线钩 ×2、红石火把 ×4 自动正确），数据包改配方自动跟随；
- **材料即门槛**：原料箱里放什么原料，才做得出对应产物；布线/机关线没选天赋时，弹层里根本不出现那些配方。

### 工人天赋（3/6/9 级各选一，与战士树同构）

| 节点 | 分支 A | 分支 B |
|---|---|---|
| 精通 Lv3 | **效率**：合成速度 +20%，但饥饿速度 +50% | **节能**：合成速度 -20%，但饥饿消耗 -50% |
| 大师 Lv6 | **布线**：解锁传递/改变信号元件 | **机关**：解锁接收信号元件 |
| 传奇 Lv9 | **开源**：每件产出 10% 概率 +1 | **节流**：整次合成 10% 概率免料 |

### 作息与边界

- 工作时段 `craft.workStartTick~workEndTick`（默认 2000~10000，起床后/睡前留空闲）；觅食永远优先于工作；
- 睡觉/吃饭/心情与普通镇民完全一致（睡眠惩罚照常结算，无战士豁免）；
- 面板状态行实时显示：工坊绑定/订单/阶段（取料中·合成中·入库中）。

## 3.5 簿记员 ✅（v0.8.1 实装）

**定位**：信息向职业——统计城镇容器物资、带玩家去找指定物品。不生产、不战斗。

### 城镇物资统计

- **每日一次**（当天幂等）+ 面板"查询物资"按需触发；扫描走**摊派式预算**（每 tick 4096 格），对 TPS 零感知；
- 扫城镇外框全部容器（一切实现 Container 的方块实体）+ **唱片机里的唱片**（唱片机不是 Container，单独收录）；
- 扫描完成后**自动推送**给请求者并直接弹出搜索界面（不用点第二次）。

### 寻物（创造模式风格搜索界面）

1. 面板"查询物资" → 搜索屏：顶部搜索框（回车过滤，物品名/注册名子串）+ 下方滚动网格；
2. **数量角标三级精度**（按簿记员段位）：
   | 段位 | 精度 |
   |---|---|
   | 生疏 / 入门（0~249 经验） | 只显示物品（有/无） |
   | 熟练 ~ 精通（250~899） | 数量级（≤10 / >10 / >100 / 1000+） |
   | 老练及以上（900+） | 精确数字 |
3. **点物品** → 界面关闭 → 簿记员带路去**离玩家最近的**装有该物品的容器 → 到达后对容器撒**施肥绿粒子 10 秒**；城镇里没有 → 聊天提示"没有找到"。

### 在职成长

- **只要在职，每 5 秒 +1 簿记经验**（用户定稿，与劳动行为解耦）；约 21 分钟升数量级精度、75 分钟升精确；
- perk 暂未设计（v0.8.1 用户定稿先不做）。

### 实现边界

- 寻物基于**统计缓存**：当天没扫过就先提示"正在盘点"，完成自动弹窗；跨天数据过期自动重扫；
- 中途换目标（绿光还亮着时点新物品）立即换单重新出发，无残留状态。

# 卷四 · 喜好、心情与性格

## 4.0 总则 ✅

- 喜好是**真生效的行为调制器**，不是展示数据；
- 一切心情变化走统一管线：事件限流 → 想法落日志；**每日结算不限幅**（clamp 机制 v0.8.1 已取消，默认关闭；想启用可配 `mood.dailyClamp`，挨饿本就绕过限幅）；
- 想法**只显示措辞不显示数值**，三色：正面绿 / 负面红 / 中性灰；
- 每人偏好出生随机抽取（乘法概率分布），测试用 `/bmfstown reroll` 重摇。

## 4.1 食物口味 ✅（必出：甜 或 肉）

- 吃到对口味的食物：**+3**，每天 2 次；
- 箱子拿取、背包进食都遵循"爱吃的优先"（见 2.2 挑食规则）。

## 4.2 职业喜好 ✅（必出：喜欢 1 个）

- 文案写**活动**不写头衔："喜欢战斗"而非"喜欢战士"；
- 每日结算：当天干的是喜欢的 → **+3**（按指派判定）。
- 讨厌职业已退出心情体系（v0.8：职业只有战士，讨厌=自相矛盾）。

## 4.3 建筑方块材质 ✅（0~2 种，各 1/2 概率）

- 25 种材质家族，**注册名前缀匹配**——楼梯/台阶/门/活板门自动覆盖：

> 石头系：石头、深板岩、花岗岩、闪长岩、安山岩、凝灰岩、**方解石**、砂岩、红砂岩、黑石

# 卷七 · 机制备忘（开发者速查）

> 给"时间久了记不住自己怎么写的"自己的。逐条对应代码位置。

- **"一天"** = `dayTime/24000`（`MoodState.currentDay`）；`settleOffset` 落 NBT，与 `lastSettledDay` 成对读写，绝不能读档重随；
- **long 间隔闸门**：`last == Long.MIN_VALUE || now - last >= interval`（防哨兵值减法溢出）；
- **挑食进食**（`HungerSystem.findFoodSlot`）：三轮扫描——能吃的爱吃的 → 存在性检查（有爱吃的就拒普通）→ 普通里挑营养最低；"不浪费"门槛 = `canEatWithoutWaste`；`allowWaste`（回血优先）无视一切；续吃判据在 `Resident.finishBite`，必须与门槛一致；
- **偏好拿取**（`Resident.takeFromContainer`）：同结构两轮扫描，先爱吃后普通；
- **住宅区材质扫描**（`HomeMaterialScanManager`）：每镇民每天一个 Job，每 tick 全服 4096 格摊派、命中即停、跨天弃扫、gameTime 去重；由 `Resident.customServerAiStep` 驱动；扫完回调 `MoodState.applyHomeMaterialResult`；方块注册名用 IdentityHashMap 缓存；
- **homePos**：镇民躺下时登记（`lieDown` → `withHomePos(bed)`），换床自动更新；
- **敌对生物检测**：一律 `getEntitiesOfClass(Mob.class) + instanceof Enemy`——`Monster` 漏史莱姆/岩浆怪（v0.8.1 教训）；`getEntitiesOfClass` 只收类不收接口；
- **菜单按钮状态**走 `SynchedEntityData`，不走 ContainerData（同步不可靠）；瞬态可视化（嘲讽红罩）走"S→C 广播 UUID+截止 gameTime，客户端按本地时间轴过期"模式；
- **索敌节流**：Goal 自持计数器，禁 `tickCount % N`（原版按 (tick+实体ID)%2 单双号调度）；
- **网关编码**：1.21.1 没有 `ByteBufCodecs.list(codec)`；裸 ByteBuf 没有 readUtf/readVarint；
- **语言文件**：含 `%` 必须 `%%` 转义；`RandomSource` 在 `net.minecraft.util`；
- **编译排错**：javac 错误全量人工过目，别 grep 过滤（会漏 illegal forward reference 等）；噪音只有 cannot find symbol / package does not exist / does not override / no suitable method 四种级联；
- **DEBUG 日志**：常态路径别放（dev 全打、玩家看不见）；排障信息要么删要么升 WARN 带坐标。
