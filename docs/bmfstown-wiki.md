# 卷六 · 调试命令与测试手法

## 6.1 调试命令 ✅（均需作弊权限）

| 命令 | 作用 |
|---|---|
| `/bmfstown hunger <目标> <值>` | 设置饥饿值（0~20） |
| `/bmfstown mood <目标> <值>` | 设置心情值（0~100） |
| `/bmfstown skillxp <目标> <值>` | 设置技能经验（0~7500，验段位/效率/perk） |
| `/bmfstown reroll <目标>` | 重摇全部随机偏好（含职业好恶与口味；不动饥饿/心情/技能） |

目标支持全部原版选择器。**最近的一个镇民**：
`/bmfstown reroll @e[type=bmfstown:resident,limit=1,sort=nearest]`

## 6.2 标准测试手法

- **跳天**：`/time add 24000`（每日结算必触发一次；相位随机但跳天按调整日计数，跳一天必换一天）
- **天气**：`/weather clear|rain|thunder`；注意天气事件双限流（半天 1 次 + 变了才触发），连测用 `/time add 12000` 清间隔
- **面板同步**：想法/偏好/心情只在开面板瞬间下发——动作后**重开面板**

# 卷七 · 机制备忘（开发者速查）

> 给"时间久了记不住自己怎么写的"自己的。逐条对应代码位置。

- **配方反查**：工人配方绝不手写——白名单只圈产物域，材料/产量从 `RecipeManager` 真实配方实时反查（v0.8.1 第一版硬编码配方被批"凭记忆猜不对"后定下的铁律）；
- **containerFx 原语**：开箱开关盖动画+音效与觅食共用同一套 containerFx 原语——新增"对容器做动作"的表现直接复用，别另写；
- **"一天"** = `dayTime/24000`（`MoodState.currentDay`）；`settleOffset` 落 NBT，与 `lastSettledDay` 成对读写，绝不能读档重随；
- **long 间隔闸门**：`last == Long.MIN_VALUE || now - last >= interval`（防哨兵值减法溢出）；
- **挑食进食**（`HungerSystem.findFoodSlot`）：三轮扫描——能吃的爱吃的 → 存在性检查（有爱吃的就拒普通）→ 普通里挑营养最低；"不浪费"门槛 = `canEatWithoutWaste`；`allowWaste`（回血优先）无视一切；续吃判据在 `Resident.finishBite`，必须与门槛一致；
- **偏好拿取**（`Resident.takeFromContainer`）：同结构两轮扫描，先爱吃后普通；
- **住宅区材质扫描**（`HomeMaterialScanManager`）：每镇民每天一个 Job，每 tick 全服 4096 格摊派、命中即停、跨天弃扫、gameTime 去重；由 `Resident.customServerAiStep` 驱动；扫完回调 `MoodState.applyHomeMaterialResult`；方块注册名用 IdentityHashMap 缓存；
- **homePos**：镇民躺下时登记（`lieDown` → `withHomePos(bed)`），换床自动更新；
- **敌对生物检测**：一律 `getEntitiesOfClass(Mob.class) + instanceof Enemy`——`Monster` 漏史莱姆/岩浆怪（v0.8.1 教训）；`getEntitiesOfClass` 只收类不收接口；
- **菜单按钮状态**走 `SynchedEntityData`，不走 ContainerData（同步不可靠）；瞬态可视化（嘲讽红罩）走"S→C 广播 UUID+截止 gameTime，客户端按本地时间轴过期"模式；
- **索敌节流**：Goal 自持计数器，禁 `tickCount % N`（原版按 (tick+实体ID)%2 单双号调度）；
- **网关编码**：1.21.1 没有 `ByteBufCodecs.list(codec)`；裸 ByteBuf 没有 readUtf/readVarint；
- **语言文件**：含 `%` 必须 `%%` 转义；`RandomSource` 在 `net.minecraft.util`；
- **编译排错**：javac 错误全量人工过目，别 grep 过滤（会漏 illegal forward reference 等）；噪音只有 cannot find symbol / package does not exist / does not override / no suitable method 四种级联；
- **DEBUG 日志**：常态路径别放（dev 全打、玩家看不见）；排障信息要么删要么升 WARN 带坐标。

# 卷〇 · 设计北极星（所有取舍的尺子）

> **"第一人称的模拟人生——玩家不是管理城镇的上帝，而是和这些有脾气的小人住在一起的邻居。"**
> 引入模拟市民级的真实度与复杂度，但玩家与世界是**同一人称**：一切模拟状态都应有"世界内的表达"
> （气泡/行为/粒子），面板只是备用的查户口工具。

**护栏问题**（每个新功能过一遍）：玩家是在世界里**"遇到"**这个反馈，还是在 UI 里**"查到"**这个反馈？前者做，后者降级为辅助。

**正反馈主循环**（2026-10-28 讨论定稿）：② 离线生长的活家园（回城时镇子变了——产出/成长/事件在玩家不在时推进）+ ① 培养绑定（"这是**我的**人"——个性表达频率决定情感浓度）双轮，③ 稀有收集当佐料；④ 城镇即工程（MineColonies 式建造升级）**不做主驱动**。

**认知探索框架**（2026-10-29 讨论定稿）：MC 无预设地图，卖不了空间探索；**"知识是这个 mod 的核心资源"**——明面进度（经济/建设/熟练度）之外还有一条暗线进度（发现/传说/禁忌），暗线解锁明面的新分支。五大基础设施：

| 基建 | 设计要点 |
|---|---|
| **发现图鉴**（脊柱） | 持久化"已知知识"：只记录见过的、**绝不预告没见过的**（反 wiki 化的技术保障）；状态三档 未知→有线索→已确认；条目记来源（=年史原料） |
| **线索链** | 每个秘密 ≥2 条路：撞见路（自然碰到）+ 追查路（顺藤摸瓜）；**传声筒全部是镇民**（台词/想法/行为），不弹窗不教学 |
| **实验面** | 隐藏词条 = 触发条件 + 效果 + 模糊提示 三元组；游戏旁观玩家行为，条件命中词条浮现；**试错必须可复现**（非玄学） |
| **研究经济**（学院/学者） | 研究不产出答案，只产出**线索与半成品**（"神器大概和水有关"）；进度全镇共享；深处有**禁忌标记**——发现的风险不对称（力量+代价），黑魔法研究院并入此线 |
| **隐藏内容登记表** | 统一结构 {id, 类别, 解锁条件, 线索挂点}；隐藏特性进"隐藏池"（发现前不进随机抽取，与特质权重结构配合）；隐藏职业以事件来访/镇民觉醒入场 |

**表达层落地设计（2026-10-29/30 讨论，发现框架的地基）**：

**① 事件总线**（一切的地基）：镇民事件（感知扫描/每日结算/行为观察）结算后统一产生 `TownEvent{type, 时刻, 主体, 相关玩家/镇民/物品/位置}` 广播给订阅者（台词/记忆/职业解锁/图鉴）。产生方只管喊一嗓子，加新玩法=多登记一个订阅者。

**② 记忆仓（第七域 MemoryState，跟人走）——双轨制（2026-10-30 修正）**：**印象**（短期：衰减、归零即忘，只做台词素材与闲聊池）+ **铭记**（达阈值固化、永不衰减：单次重大/重复累积两路径，带回味触发器=条件→效果）。归属铁律：记忆只来自亲历、纯个人制——图鉴/解锁表才是世界级共享。完整展开见下方"记忆双轨"补充定稿。

**③ 台词引擎**：`DialogLine{条件谓词列表, 权重, 冷却组, 优先级}` 静态注册表；谓词=现成状态组合（天气/时段/心情/性格/手中物品命中诱饵表/HAS_MEMORY/图鉴线索挂点）；错相位评估+限频。

**④ 职业解锁表（世界级 SavedData，与图鉴同族）**：`{解锁集合(初始只有战士), hooks: 诱饵物品→需目击行为→需记忆}`；迁徙波次只出已解锁职业（镇民来源联动，猪灵族=地狱门解锁后）。

**⑤ 展示形态（定稿）**：**命名牌同款渲染**——半透明深底+白像素字浮在头顶，名字牌照旧在下，台词短句≤20字单行，淡入淡出+16格距离衰减；**耳语型=同款样式定向投递**（数据只发被说话者客户端，旁人不可见）；聊天栏只收定向/线索双写（留档可回读）与全镇公告，氛围台词不进。实现可评估原版 text_display。

**⑥ 多人冷却（二维）**：宣言型=镇民级冷却（说给空气听一遍即可）；定向型=**镇民×冷却组×玩家** 三维记账（每人独立拥有"第一次相遇"）；镇民级"每分钟 N 句"节流阀防复读机，优先级高的先说（线索>好奇>氛围）。

**② 补充定稿（2026-10-30，记忆双轨+触发源分类）**：

**记忆双轨**（替代单轨衰减模型）：
- **印象（短期）**：日常事件小卡片，带强度、衰减、归零即忘——只做台词素材与闲聊池（"昨天那鱼真肥"）；
- **铭记（永久）**：达到程度才固化，刻进数据**永不衰减**。两条固化路径：A 单次重大（强度爆表一次跨阈值：被救/目睹死亡/禁忌异象/血战）；B 重复累积（单次平平反复发生攒够：讨厌下雨+天天下雨→"那段淋雨的日子"）。偏好（Prefs）是天生脾气，铭记是人生经历——两层。
- **回味触发器**：每条铭记带 {触发条件→效果}（淋雨日：下雨天心情额外修正+抱怨台词；血战：进战斗概率战意 buff+战吼；救命之恩：见到恩人心情转好+主动招呼）。效果逐类单独定义，机制统一——记忆成为性格的第二层。
- **归属铁律**：记忆永远个人制、只来自亲历（谁在场谁记），无"城镇集体记忆"对象。分界句：**图鉴/解锁表=世界的记忆（可共享）；MemoryState=个人的记忆（只来自亲历）**。

**触发源三类**（事件上的来源标签，决定默认节奏与优先级）：
- **self 自身日常**（吃饭/闲逛/去图书馆）→ 低频错峰，街道活气，无玩家在场也活着；
- **player 玩家交互**（经过/评论装备/被救）→ 中频按玩家分账，"玩家被看见"；
- **secret 隐藏事件**（线索/禁忌异象）→ 极低频+高优先，发现系统的追查路入口。
判定规则：秘密挂点优先于普通评论（拿着神器路过学者触发线索而非"好奇怪的铁棍"）。事件过后转入闲聊池低概率回响（"回忆杀"），随印象衰减自然退役——"随机的话"背后全是延迟回响的经历。

**台词节奏四档**：事件反应（瞬间触发+短冷却）/ 好奇类（中频按玩家分账）/ 线索类（**慢频循环**：首说后隔 1~2 天重提，秘密确认后自动退役——不可一次即弃，玩家可能没看到且无任务系统兜底）/ 氛围闲聊（低频错峰，素材=未淡忘的印象与铭记）。

**台词池三交集**：城镇状态（公共池，对所有人一样，总量守恒）∩ 镇民个性（性格/记忆/心情定说辞）∩ 玩家情境（在场/手持/私人记忆）——私人池（"你上周救过我"）每人一份不共享。

**渔夫全链路示例**：拿鱼路过无业镇民→好奇台词+记 CURIOSITY(fish)→带去水边他旁观钓鱼成功→记忆晋升→**世界解锁渔夫**+全镇广播→面板出现渔夫职业（首个转职者专属台词）。一条管线，新职业全是内容配置。

**内容点子池**（均挂上表）：传闻失真（八卦传三手走样，辨真伪即玩法）· 镇民梦境漏线索 · 奇遇事件（流星/无名小冢/井中声）· 古物残片（日常劳动的低概率钩子）· 城镇年史实体化（图书馆可翻阅）。

**最小闭环**：发现图鉴数据层 + 登记表 + 试点内容（建议=隐藏特性，成本最低：特性系统/权重/想法日志全现成）→ 跑通"未知→线索→确认→入池"后，神器/神谕者/学院皆为挂内容。

# 卷八 · 路线图（按系统分类）

> 分类维度 = **改动落在哪一摊**：①现有系统增量 → ②选区与城镇 → ③镇民本体 → ④职业线 → ⑤新概念。
> 动工原则：**一次只开一个分类**，跨分类并发是大坑。"⏸ 待拍板"= 动工前先定参数。
> 落点顺序建议见文末"下手路径"。

## 一、现有系统的增量（不新增概念，做完即收）

| 项 | 挂在哪 | 说明 |
|---|---|---|
| **特质概率位** ✅（v0.9.1） | TraitType.weightedRandom | 权重数据结构：`traits.weightOverrides` 覆盖表（"id:权重"，未列出默认 1，空表=等概率与旧版一致）；权重 0=禁用该条；单条上限 10 万。**不做空特性（用户定稿）**——全员必抽，只做概率结构为词条扩容打底 |
| **特性第二批行为** | TraitState（tickTraits 分支） | 漫游癖（⏸ 心情值，倾向 +3）/ 自毁倾向（⏸ 爆炸半径，倾向 1.5~2 格不毁方块）/ 蛋蛋人（⏸ 蛋判定范围，倾向全算）/ Dylar实验对象 / 舍己为人（依赖超情绪，可先做基础嘲讽） |

## 下手路径建议（依赖 + 性价比）

```
①不连续选区（小,解锁型）→ ②特质概率位+特性第二批（同一摊一锅端）
→ ③需求系统（大,救活城镇）→ ④厨师+本命食物（中）
→ ⑤图书馆/教堂（选区增量）→ ⑥学者/书（新概念,远期）
```

原则：**按分类串行推进**——每个分类做完收口一次（实测+commit），不跨分类并发。
已拍板的否定决策：镇民不自给自足（保"玩家供食换服务"循环，生产缺口靠厨师）；全员必有特质要改（加"普通"概率位，不是把词条概率全调小）。
