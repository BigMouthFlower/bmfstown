# bmfstown 实测总清单（截至 2026-11-16 夜，含未 commit 的 #67/#68/#70）

> 用法：逐条打勾验收。每条都是"操作 → 通过判据"。
> 末尾附"设计内行为"防误报表——这些看到**不要**当 bug 报。

## 通用口径（对齐代码实现）

- **登记容器**：划工坊/酒窖时登记进池子的箱子/木桶（职业只认登记池，不认野箱子）。
- **每日一杯**：同一游戏日内每个镇民最多触发一次酒馆消费（按天记档）。
- **遇险**：被攻击或被怪物锁定为目标。
- **缺料播报**：16 格内 actionbar 提示缺口，30 秒节流不刷屏。
- **归时表演**：开盖→倒货→10 刻（0.5 秒）后自动关盖（含音效）。
- **行为结束空手**：任何行为结束主手恢复为空（#49 契约），空手不是 bug。

## 1. 酒馆消费链（#63~67，重点）

**布景**：酒馆区（楼梯椅+下半砖椅、酒窖容器、酒保 1 名）、若干镇民、装了 BAC 时酒窖里放 BAC 酒。

| # | 操作 | 通过判据 |
|---|---|---|
| 1.1 | 闲暇时段镇民进酒馆 | 走向楼梯/下半砖坐下（真坐姿，两种材质都不悬空不陷地） |
| 1.2 | 看坐下后动作 | 坐定**立即**点单+打铃，无延迟 |
| 1.3 | 看酒保反应 | 点单瞬间受理（不等 5 秒扫描），走到客人身边塞酒 |
| 1.4 | 盯喝的过程 | 举瓶仰头、原版时长（药水 32t/蜂蜜 40t/奶桶 32t），各物品出**各自的**原版音效（重点复听蜂蜜瓶） |
| 1.5 | 多人多天 | 喝的种类随机（窖里有几种就随机抽），无"永远蜂蜜" |
| 1.6 | 喝完观察 | 起身还杯进容器→回**原座位**坐到段尾→走人 |
| 1.7 | 封死全部座位 | 站着点单兜底，流程照走 |
| 1.8 | 等单 30 秒不塞酒 | 客人起身**自取酒窖**（随机一瓶），回来坐到段尾——夜间无酒保时这是常态 |
| 1.9 | 等单时打他 | 立即起身不占杯；正在喝的当场喝完+还杯（"点了就喝完"） |
| 1.10 | 同人当日二进馆 | 不再消费；次日可再来 |
| 1.11 | 酒窖无酒 | 点单落空，改天再来，不卡死 |
| 1.12 | 有 BAC 时 | BAC 酒可被点/被喝/药效照常；卸掉 BAC 后 tag 静默回落原版三样，不炸 |

## 设计内行为防误报表（看到这些不是 bug）

| 现象 | 原因 |
|---|---|
| 夜里客人自己进酒窖拿酒喝 | 点单 30 秒等不到酒保（下班了）→ 超时自取兜底 |
| 酒保下班后自己点单自己喝 | 决策 #69 保留的彩蛋（每日一杯闸门兜底不刷杯） |
| 《夜半异响（测试线）》占位文 | 恐怖线唯一登记的书线，正式内容待书单定稿 |
| 名字池"姓 0×名 0" | 姓/名名单未定稿，整名名单（20 个）正常生效 |
| 下班后箱里装不下的材料留身上 | 归还绝不吞货的铁律：全容器满 → 揣着，下批再试 |
| 归还只在 4 格内发生 | #72 距离判定：容器超出 4 格不隔空放货，他**自己走过去**再还（优先级压过闲暇，让位逃跑/开门）；存档重载后待还丢失=留身上下次重试 |
| 行为结束主手空手 | #49 契约：下一行为换装，不做"恢复原物" |
| 酒馆喝奶桶后没有空桶 | 原版对 mob 的口径（奶桶不产生桶），杯按预算另还 |
